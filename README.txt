ANEESHA WATVE — PRODUCT STRATEGY & UX PORTFOLIO

FILES
- index.html: responsive portfolio website
- assets/: project imagery and strategy diagrams

PREVIEW LOCALLY
1. Unzip the package.
2. Open index.html in a modern browser.
3. Keep the assets folder beside index.html.

PUBLISH
- Netlify Drop: drag the unzipped folder into app.netlify.com/drop
- GitHub Pages: commit the files to a repository and enable Pages
- Vercel: import a repository containing the files
- Any static host: upload index.html and assets together

A self-contained HTML version is also included as a separate download. It embeds all imagery and can be opened directly without an assets folder.
